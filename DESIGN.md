# Design direction
Landing = Persuade / Experience: original comic art is the evidence. Large Barlow Condensed promise, a short sample-chat-to-panel assembly, lime editorial interlude, dark/paper magazine contrast. No stock imagery, new dependencies, CDN fonts, emoji icons, vanity metrics or decorative glass.
Studio = Operate: compact32px workspace heading, quiet neutral chrome, wide comic canvas, compact replay transport, editor desk, honest moment markers. Fixture velocity is explicitly illustrative because the current API has no measured velocity series.
Recap = Experience / Read: paper issue, large cover type, opening spread, dark moment splash, sticky sharing. Art remains16:9; rails expand for every line and exports may grow vertically.
Motion: one landing explanation sequence;180ms chat state and240ms panel arrival using existing ease-out token, transform/opacity only. No scroll listeners, render-per-frame React updates or new motion dependencies. Reduced motion resolves all art immediately. Keyboard controls retain visible focus; frequent approval actions gain no new animation.
Responsive:390/768/1440/1920. At390 one featured assembling panel, flowing caption rail and stacked magazine/style sections; both complete art styles remain visible below. Desktop shows the full three-panel strip. Data stress uses the existing manifest-driven long-English/RTL/emoji suite rather than a production data toggle.
