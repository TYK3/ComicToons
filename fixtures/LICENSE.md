# Fixture and art license

All sample streams, invented chat, characters, and SVG artwork in this repository were created for ComicToons. The project contributors dedicate these original fixture and art assets to the public domain under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). No third-party fonts, characters, logos, or likenesses are used.

The live mock image provider generates the original SVG artwork in `packages/core/src/art.ts`; captions and dialogue are HTML, never embedded in images.

The six vector compositions depict a crystal vault, a key-stealing familiar, a tumbling die, a victory party, a platform leap, and a pancake flip. Each uses original paths and geometric shapes. `fixtures/art/explorer-1.svg` through `explorer-6.svg` are generated snapshots of those same scene definitions.
