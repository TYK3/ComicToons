# Generated art provenance

These images were made with OpenAI image generation (the built-in `image_gen` tool, via the Codex CLI and a ChatGPT login) for the ComicToons hackathon project (Codex x TwitchCon Hackathon). Prompts requested original characters only (Nova, Pixel, Chat Crowd), with no text, logos, real people or brand characters. Raw generations were centre-cropped to 16:9 and resized to 1280x720 WebP. Treat them as AI-generated and label them as such in the UI. Check OpenAI's current terms for the output before any use beyond this demo.
